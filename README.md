# ArduPilot Improvements

An independent community lab for ArduPilot bug fixes, feature proposals,
interoperability, diagnostics, and reproducible testing. Not an official
ArduPilot project.

**Status:** tracking hub prepared; next, after the Betaflight pilot. Discovery and coding are not
running for this stack yet.

## Track work here

Use [issues](https://github.com/DroneWuKong/ardupilot-improvements/issues/new/choose)
for sourced requests with expected behavior, existing work, scope, and acceptance
criteria. Small changes go through reproduction and regression testing. Larger
proposals get design review before implementation.

The shared process is being exercised in the
[Betaflight pilot](https://github.com/DroneWuKong/betaflight-improvements).
The rollout order is Betaflight, ArduPilot, then PX4.

Public work should explain the general technical benefit. Keep private
integration notes and product-specific planning outside this repository.
No automated merge, firmware publication, or hardware deployment is configured.
